# 🎯 DÉMARRAGE EN 3 ÉTAPES

## Étape 1: Installer (2 min)

Sur **Windows:**
```
Double-cliquez sur run.bat
(tout s'installe automatiquement)
```

## Étape 2: Lancer (automatique)

L'application s'ouvre dans votre navigateur:
```
http://localhost:8501
```

## Étape 3: Utiliser (5 min chaque module)

**Module 1** → Vérifiez les charges  
**Module 2** → Voyez la répartition  
**Module 3** → Confirmez les transfers  
**Module 4** → Consultez les CUO  
**Module 5** → Entrez votre commande  
**Module 6** → Générez votre devis ✅
