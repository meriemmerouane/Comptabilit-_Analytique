## ÉTAPE 3: CALCUL DES COÛTS D'UNITÉ D'ŒUVRE

### Unités d'œuvre du mois (données du mois complet)

```
APPRO   → 12,000 mètres (tissus/fournitures)
AT-D    → 7,200 mètres coupés
AT-ML   → 2,400 heures MOD
DIST    → 1,800 tenues
```

### Calcul des CUO

**APPRO:**
```
CUO = Total du centre ÷ NUO
CUO = 99,204 ÷ 8,400
CUO = 11.81 DA/kg
```

**AT-D:**
```

```

**AT-ML:**
```
CUO = 282,468 ÷ 2,400

```

